# Tiago Moura - modelosdeskills

## O que é isto

Sou Tiago Moura, profissional de Tráfego Pago desde 2015. Uso o Claude Code todo dia na minha
operação e, como não programo, fui criando skills pra me proteger dos erros que eu mesmo poderia
cometer: senha em código, arquivo errado subindo pro git, skill que parece boa e não é.

Este repositório junta versões genéricas dessas skills, pra quem trabalha em contexto parecido com
o meu. Não é produto — é o retrato de uma operação real.

## Skills

Cada skill tem o próprio zip na aba **Releases** e um README próprio dentro da pasta, com o que ela
faz e como instalar.

| Skill | Pra quem é | Pasta |
| --- | --- | --- |
| `/seguranca-verificar` | Quem montou um projeto com assistente de IA, não programa, e quer saber se deixou senha no código, arquivo de cliente exposto ou o login desprotegido. Encontra, explica em linguagem simples e corrige. | [seguranca-verificar](seguranca-verificar/) |

## Adapte à sua realidade

Rode, teste, ajuste e molde cada skill ao seu projeto antes de confiar nela. O que está aqui é
ponto de partida, não padrão.

## Responsabilidade

Uso por sua conta e risco. Os efeitos diretos e indiretos de instalar e executar qualquer skill
deste repositório são de responsabilidade de quem instala e executa, não minha. Leia cada skill
antes de usar, teste primeiro num projeto sem dado importante e mantenha backup do que for seu. A
licença MIT diz isso em termos legais ("sem garantia de qualquer tipo"); este parágrafo diz em
português claro.
